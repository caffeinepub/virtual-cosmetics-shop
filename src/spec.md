# Specification

## Summary
**Goal:** Replace generic beauty cosmetics with approximately 50 Gorilla Tag themed items in the shop.

**Planned changes:**
- Replace existing cosmetic items (eyeshadow, lipstick, nail polish, perfume) with approximately 50 Gorilla Tag themed cosmetics including finger painter, AA badge, illustrator badge, stick, forest guide, and other iconic items from the game
- Update shop interface to display new Gorilla Tag themed cosmetic names and imagery
- Maintain existing £10 price point, purchase system, balance tracking, and owned items functionality

**User-visible outcome:** Users will see a shop filled with approximately 50 Gorilla Tag themed cosmetics (like finger painter, AA badge, illustrator badge, stick, forest guide) instead of generic beauty items, all purchasable for £10 with the same shop functionality.
